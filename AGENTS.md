# IPD Workflow Quick Reference

This project uses the **Ideas → Plans → Decisions** (IPD) workflow.
All workflow artifacts are stored in the hidden `.ipd/` directory.

## Core Loop
1. **Idea**: Capture a spark in `.ipd/ideas/`.
2. **Plan**: Formalize the approach in `.ipd/plans/`.
3. **Decision**: Document the final choice in `.ipd/decisions/`.

See `.ipd/AGENTS.md` for the full specification.
